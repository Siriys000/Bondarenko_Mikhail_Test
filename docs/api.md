# HTTP API

Интерактивная документация: `/docs`, альтернативное представление: `/redoc`,
OpenAPI JSON: `/openapi.json`.

## Общие параметры

`ticker` — обязательный query-параметр: `btc_usd` или `eth_usd`.
Регистр не имеет значения. Другие валюты не поддерживаются.
Время в ответе — целое число UNIX seconds, UTC. Цена — десятичная JSON-строка.

Пример объекта:

```json
{"ticker": "btc_usd", "price": "60000.123456789012", "timestamp": 1791936000}
```

## Все записи

```http
GET /prices?ticker=btc_usd
GET /prices?ticker=btc_usd&limit=100&offset=0
```

Возвращает массив в порядке `timestamp ASC, id ASC`.
`limit` необязателен, допустимые значения 1–10000; без него число записей не ограничивается.
`offset` — неотрицательное целое, по умолчанию 0.

## Последняя цена

```http
GET /prices/latest?ticker=eth_usd
```

Возвращает один объект с максимальным `timestamp`; при равенстве выбирается больший `id`.
API читает только сохранённые данные и не делает запрос к бирже.

## История по дням

```http
GET /prices/history?ticker=btc_usd&date_from=2026-10-01&date_to=2026-10-14&limit=100
```

`date_from` и `date_to` обязательны, формат `YYYY-MM-DD`.
Обе календарные границы включены в UTC. Для одного дня передайте одинаковые даты.
Допустимый диапазон — от `1970-01-01` до `9999-12-30`; начало не может быть позже конца.
Для `2026-10-14` выбирается интервал от `2026-10-14T00:00:00Z` включительно
до `2026-10-15T00:00:00Z` исключительно. Поддерживаются `limit` и `offset`.

## Ошибки

| Статус | Условие |
| --- | --- |
| 200, `[]` | Нет записей в истории или на странице |
| 404 | Последняя цена ещё не сохранена |
| 422 | Нет ticker, неизвестная валюта, неверные даты или пагинация |
| 503 | БД временно недоступна |

Ответы с ошибками содержат поле `detail`.
